- Git blob SHA: `0d78fac368ee81197179648854aa8b233388d6da`

The upstream README notes that some project data was extracted manually or automatically from wiki.vg and minecraft.gamepedia.com; consult the upstream repository for its complete data provenance. The build embeds each item's name and display name in the app.
