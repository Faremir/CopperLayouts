# Third-party data

`data/items.json` is generated from the PrismarineJS contributors' `minecraft-data` project. Item records are retained, with JSON formatting normalized for this repository.

- Upstream: https://github.com/PrismarineJS/minecraft-data
- Exact version, revision, source URL, record count, and checksum: `data/items.meta.json`
- Upstream license declaration: **MIT**, as stated in https://github.com/PrismarineJS/minecraft-data#license

The upstream README notes that some project data was extracted manually or automatically from wiki.vg and minecraft.gamepedia.com; consult the upstream repository for its complete data provenance.
